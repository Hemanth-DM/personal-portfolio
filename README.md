# Hemanth D.M. - 3D Interactive Portfolio

Personal 3D interactive portfolio website showcasing projects, skills, education, and technical experience in Computer Science and Software Engineering.

## 🚀 Features

- **Interactive 3D WebGL Background**: Built with Three.js featuring animated particle constellations and interactive mouse parallax.
- **Modern Responsive Design**: Custom glassmorphism aesthetic with theme customization and dark neon highlights.
- **Key Sections**:
  - Professional Objective
  - Academic Background & Education
  - Technical Skills & Competencies (Java, Python, C, JSP, Servlets, JDBC, MySQL)
  - Projects Showcase
  - Certifications & Technical Seminars
  - Interactive Contact Form & Social Profiles

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3** (Custom responsive grid, flexbox, glassmorphic styling)
- **JavaScript (ES6+)**
- **Three.js** (WebGL 3D graphics rendering)

## 💻 Local Preview

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Hemanth-DM/personal-portfolio.git
cd personal-portfolio
# Open index.html directly or use a local dev server
```
